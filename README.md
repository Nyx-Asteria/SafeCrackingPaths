# Safe Cracking Paths

**Safe Cracking Paths** is a RuneScape 3 plugin that guides you between safes, highlights your next objective, and tracks your progress as you go.

## Features

- **Seven built-in routes:**
- **Guided navigation:** A directional arrow and in-world target highlights help you find safes, stairs, ladders, and other route objectives. Switch between object highlighting and tile markers.
- **Step-by-step directions:** See your current objective and travel advice in the plugin sidebar, or open **Route info** for the full route and its progress.
- **Automatic progression:** Cracked safes and supported floor changes or destination arrivals advance your route automatically. You can also select or skip steps manually.
- **Custom routes:** Build, name, reorder, edit, and delete up to five routes using the included locations.
- **Persistent progress:** Your selected route, current step, overlay preference, and saved custom routes carry over between sessions. Navigation resumes paused.


### Built-in routes

| Route | Locations |
| --- | --- |
| Misthalin | Edgeville, Varrock, Draynor, Lumbridge |
| Kharidian Desert | Menaphos, Al Kharid, Nardah, Pollnivneach |
| Menaphos Only | Merchant, Port, and Imperial Districts |
| Asgarnia | Black Knights' Fortress, Burthorpe, Port Sarim, Falador |
| Kandarin | Camelot, Yanille, Ardougne |
| Hidden | Wilderness and Zanaris locations |
| All Safes | Every included location |

## Getting started

1. Open **Safe Cracking Paths** from the RuneScape plugin sidebar.
2. Choose a route and click **Start navigation**.
3. Follow the on-screen direction indicator and highlighted objective. The plugin advances when it detects a completed step.
4. Use **Route info** to inspect the full route, jump to a step, or manage progress. Use **Custom routes** to create your own path.

### Interface

- Routing and Custom tabs.
- Route selector with location and safe counts.
- Current-step panel and route progress display.
- Custom-route editor with import/export controls.
- PrettyUI styling and native theme integration, pending API verification.

## Dependencies

**PrettyUI** is the intended required UI dependency. Its exact manifest identifier, exported functions, and compatibility need to be confirmed before the dependency is committed.
